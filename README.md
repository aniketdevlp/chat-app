# 💬 Real-Time Chat Application

A full-stack **Real-Time Chat Application** built using the **MERN stack** with **Socket.IO** for real-time communication. The application provides secure authentication, real-time messaging, online user tracking, and media sharing.

---

## 🚀 Features

- 🔐 **JWT-based Authentication**
  - Secure user registration and login
  - Password hashing using **bcrypt**

- 💬 **Real-Time Messaging**
  - Real-time bidirectional communication using **Socket.IO**
  - Instant message delivery without refreshing the page

- 🟢 **Online User Status**
  - Track users who are currently online
  - Real-time online/offline state updates

- 🖼️ **Media Uploads**
  - Upload and share media using **Cloudinary**

- 📱 **Responsive UI**
  - Responsive and modern interface
  - Built using **React, Vite, and Tailwind CSS**

- 🗄️ **MongoDB Database**
  - Persistent storage for users and messages

---

### Frontend

### Backend
